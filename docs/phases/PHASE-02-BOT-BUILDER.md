# Phase 02 — Bot Builder

## Goal

Create the first no-code bot builder UI.

## Scope

- Step list UI
- Add/edit/delete/reorder steps
- Step validation
- Store steps as JSON
- Basic preview of configured steps

## Supported Step Types

- OPEN_URL
- CLICK
- TYPE
- WAIT
- SCROLL
- EXTRACT_TEXT
- EXTRACT_LINKS
- SAVE_RECORD

## Out of Scope

- Actual Playwright execution
- AI extraction
- PDF download
- Scheduler
