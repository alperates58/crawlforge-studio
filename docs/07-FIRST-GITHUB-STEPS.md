# First GitHub Steps

## Repository Name

Recommended:

```txt
crawlforge-studio
```

Alternative:

```txt
crawlforge
```

## Initial Git Commands

```bash
git init
git add .
git commit -m "Initial CrawlForge documentation"
git branch -M main
git remote add origin https://github.com/alperates58/crawlforge-studio.git
git push -u origin main
```

## First Gemini Task

Use:

```txt
docs/prompts/GEMINI-DOCS-STRUCTURE.md
```

Then use:

```txt
docs/prompts/GEMINI-FOUNDATION.md
```

## First Build Goal

Do not build scraping first.

First build:

- Login
- Dashboard
- Project CRUD
- Bot CRUD
- Database
- Docker Compose
