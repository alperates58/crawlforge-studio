# CrawlForge

**CrawlForge** is a no-code web data extraction, document ingestion and AI-powered structured data platform.

Initial target: collecting cosmetic ingredient, INCI, supplier product page, TDS/SDS and formulation guide data.

## Purpose

CrawlForge will run under:

```txt
databot.alperates.com.tr
```

The platform allows non-developers to build data extraction bots from a visual interface.

## Core Workflow

1. Open a website
2. Login if needed
3. Click, type, wait or scroll
4. Collect list/detail links
5. Extract selected fields
6. Download PDF/TDS/SDS files
7. Use AI to extract structured data
8. Save results as draft data
9. Review and approve records
10. Export as CSV/Excel/JSON/API

## Key Principle

CrawlForge is not a captcha bypass or illegal scraping tool.

It should only be used for sources where the user has access rights and where data collection is legally and ethically acceptable.

## Recommended Stack

- React + Vite + TypeScript
- Tailwind CSS
- Node.js API
- PostgreSQL
- Prisma
- Redis
- BullMQ
- Playwright
- Docker Compose
- Coolify deployment
